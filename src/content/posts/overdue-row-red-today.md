## 結論

期限が `C列` にあるとき、行全体を選んで条件付き書式に `=AND($C5<>"",$C5<TODAY())` を設定すると、今日より前の期限の行だけが自動で赤くなります。`TODAY` は、開くたびに今日の日付を返す関数です。日付が変わると、何も触らなくても色が付く行が増えます。

完了した行は色を付けない・灰色にしたい場合は、「完了」の列を見る条件を先に1つ足します。見本ファイルには、赤・黄・灰色の3つのルールと、状態を文字で出す列を入れています。

## 期限切れが分かるタスク表の完成形

見本ファイルの内容です。基準日は2026/11/27で、色は「期限切れ＝赤」「今日が期限＝黄」「完了＝灰色」です。

| 作業 | 担当 | 期限 | 完了 | 状態 | 超過日数 | 色 |
|---|---|---|---|---|---|---|
| 見積書の送付 | 佐藤 | 2026/11/20 | | 期限切れ | 7 | 赤 |
| 請求書の発行 | 鈴木 | 2026/11/26 | | 期限切れ | 1 | 赤 |
| 月次報告の提出 | 高橋 | 2026/11/27 | | 今日まで | | 黄 |
| 備品の発注 | 田中 | 2026/11/30 | | 余裕あり | | なし |
| 契約更新の確認 | 伊藤 | 2026/11/18 | 完了 | 完了 | | 灰色 |

| 会議資料の準備 | 鈴木 | 2026/12/3 | | 余裕あり | | なし |

上の表では、期限切れが2件、今日が期限のものが1件です。契約更新の確認は期限を過ぎていますが、完了しているので赤くなりません。

## 作り方

### 1. 表を用意し、完了の列を決める

見本ファイルでは、`A列` に作業、`C列` に期限、`D列` に完了（終わったら「完了」と入力）を置き、5行目から11行目にデータを入れています。「完了」の文字を目印にして、終わったものを色の対象から外します。

### 2. 基準日のセルを作る

`B1` に基準日を入れます。実際に使うときは、次の数式を入れます。

```
=TODAY()
```

見本ファイルは動作を固定して確かめるために、`B1` に2026/11/27を直接入力しています。使うときは、このセルを `=TODAY()` に置き換えてください。数式の中に `TODAY()` を直接書く方法もありますが、基準日のセルにまとめると、「来週の時点ではどう見えるか」を日付を入れ替えて試せます。

### 3. 範囲を選び、条件付き書式を新しく作る

`A5:F11` を選びます。[ホーム]→[条件付き書式]→[新しいルール]→[数式を使用して、書式設定するセルを決定]を選び、次の数式を入れて、書式で塗りつぶしを赤系にします。

```
=AND($C5<>"",$C5<$B$1)
```

- `$C5`: 期限のセルです。列だけを固定（`$C`）して行は固定しないので、選んだ範囲の各行が、その行の期限を見ます。
- `$C5<>""`: 期限が空欄でないことを確かめます。理由は後の「つまずきやすい点」で説明します。
- `$C5<$B$1`: 期限が基準日より前（過ぎている）ことを確かめます。`$B$1` は固定して、どの行も同じ基準日を見ます。
- `AND`: 2つの条件が両方成り立つときだけ、色が付きます。

数式の最初の行は、選んだ範囲の左上（ここでは5行目）に合わせて書きます。ずれると、色が1行ずれます。

### 4. 完了した行を除く

完了を灰色にするルールを、赤より上に作ります。

```
=$D5="完了"
```

ルールの管理で、このルールを一番上にして「条件を満たす場合は停止」にチェックを入れます。上のルールが成り立った行には、それ以降のルールが適用されません。契約更新の確認のように、期限を過ぎていても完了していれば灰色のままになります。

### 5. 状態を文字でも出す

色だけだと、印刷が白黒のときや色の区別がつかない人には伝わりません。`E5` に次の数式を入れて下へコピーすると、状態が文字で出ます。

```
=IF(D5="完了","完了",IF(C5="","期限なし",IF(C5<$B$1,"期限切れ",IF(C5=$B$1,"今日まで","余裕あり"))))
```

`IF` は、条件に当てはまるかどうかで結果を分ける関数です。ここでは「完了か」「期限が空欄か」「期限が基準日より前か」「期限が基準日と同じか」を上から順に調べ、最初に当てはまったものを返します。

超過日数は `F5` に次の数式を入れます。期限切れの行だけ、基準日から期限を引いた日数が出ます。

```
=IF(E5="期限切れ",$B$1-C5,"")
```

`B2` と `B3` には `=COUNTIF(E5:E11,"期限切れ")` のように件数を出しておくと、表を開いた瞬間に遅れの数が分かります。

## つまずきやすい点

### 期限が空欄の行まで赤くなる

Excelは空欄を0（1900年1月0日にあたる値）として扱うので、`=$C5<TODAY()` だけだと、期限が空欄の行が期限切れと判断されます。数式の `$C5<>""` が、それを防いでいます。

### 期限の日に、まだ赤くなってほしくない

`<` は「今日より前」だけを指すので、当日は赤くなりません。当日も含めて赤くしたいときは `<=` にします。見本ファイルでは、当日を黄色にして区別しています。

### 日付を入れたのに色が付かない

期限が文字として入っている可能性があります。「2026.11.20」のようにドットで区切ったり、先頭に `'` が付いていたりすると、日付として比べられません。「2026/11/20」の形で入れ直すと直ります。セルが左寄せで表示されているのも、文字になっているサインです。

### 開いても今日の日付に更新されない

`TODAY` は、ファイルを開いたときや再計算されたときに更新されます。開いたまま日付をまたぐと、再計算されるまで古い日付のままです。F9キーを押すと更新されます。

### 一部の行だけ色がずれる

条件付き書式の数式で、行番号の前に `$` を付けていないか確認します。`$C5` の形で、列だけを固定します。`$C$5` にすると、全行が5行目の期限を見ます。

## 応用

- **今日が期限の行を黄色にする**: 3つ目のルールとして `=$C5=$B$1` を追加し、塗りつぶしを黄色にします。赤のルールより下に置くので、期限切れが優先されます。
- **完了の入力をなくしたい**: 完了した行を別のシートへ移す運用なら、完了の列は不要です。その場合、数式は `=AND($C5<>"",$C5<$B$1)` だけで足ります。

日付から曜日を自動で表示する方法は、[日付の横に曜日を自動表示する方法](/hukugyou/posts/date-weekday-auto-display/)で扱っています。期限の日を営業日で計算したいときは、[営業日後の納期を出す方法](/hukugyou/posts/workday-deadline-business-days/)が使えます。

見本ファイルで動きを確認できます。基準日のセルの日付を変えてみると、色が切り替わるのが分かります。

## よくある質問

### 期限切れの行全体を赤くするには？

色を付けたい範囲（例: `A5:F11`）を選んでから条件付き書式を作ります。数式の列に `$` を付けて `$C5` の形にすると、選んだ範囲の全体が、その行の期限で色が決まります。

### 完了した行を赤くしないようにするには？

「完了」の列を見るルールを一番上に作り、「条件を満たす場合は停止」にチェックを入れます。上のルールに当てはまった行には、下の赤のルールが適用されません。

### 期限が空欄の行が赤くなるのはなぜですか？

Excelが空欄を0として扱い、「今日より前」と判断するためです。数式に `$C5<>""` を加えて、空欄を除きます。
