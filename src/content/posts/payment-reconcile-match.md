## 結論

入金消込（請求に対して入金があったかを突き合わせて、請求を済みにする作業）は、請求ごとに `SUMIF` で入金額を合計し、請求額との差額で状態を判定すると、Excelで自動化できます。請求番号が `A2`、請求額が `C2` にある場合の数式は次の3本です。

```
=SUMIF(入金一覧!$B$2:$B$8,A2,入金一覧!$C$2:$C$8)
=C2-D2
=IF(D2=0,"未入金",IF(E2=0,"消込済",IF(E2>0,"不足あり","過入金")))
```

見本ファイルでは請求6件のうち、消込済2件・不足あり1件・過入金1件・未入金2件と判定されます。

## 作り方

### 1. 入金額を請求ごとに合計する

請求一覧の `D2` に次の数式を入れ、下へコピーします。

```
=SUMIF(入金一覧!$B$2:$B$8,A2,入金一覧!$C$2:$C$8)
```

- `SUMIF(条件の範囲, 条件, 合計する範囲)`: 条件に合う行だけを合計する関数です。
- ここでは、入金一覧の請求番号（`B列`）が `A2` と同じ行の入金額（`C列`）を合計します。
- `$` を付けた範囲は、下へコピーしてもずれません（セル範囲を固定する書き方）。

1つの請求に2回に分けて入金されても、合計されるので判定できます。`INV-003` は100,000円と120,000円の合計で220,000円になり、消込済です。

### 2. 差額を出す

`E2` に `=C2-D2` を入れます。プラスなら不足、マイナスなら入金が多い状態です。

### 3. 状態を判定する

`F2` に次の数式を入れます。

```
=IF(D2=0,"未入金",IF(E2=0,"消込済",IF(E2>0,"不足あり","過入金")))
```

上から順に、入金がゼロなら未入金、差額がゼロなら消込済、差額がプラスなら不足あり、それ以外は過入金を返します。

### 4. 請求のない入金を見つける

入金一覧の `D2` に次の数式を入れ、下へコピーします。

```
=IF(COUNTIF(請求一覧!$A$2:$A$7,B2)=0,"請求なし","照合済み")
```

`COUNTIF` は、条件に合うセルの数を数える関数です。請求一覧にない請求番号なら、0件となり「請求なし」と出ます。見本では `INV-007` が該当します。番号の入力ミスの発見にも使えます。

### 5. 状態ごとの件数を数える

見本ファイルの `I2` には `=COUNTIF($F$2:$F$7,H2)` を入れ、`H列` に書いた状態名ごとの件数を出しています。

## 消込がうまくいかないとき

### 入金があるのに「未入金」になる

請求番号の表記がそろっていない可能性があります。全角と半角、末尾の空白が違うと、別の文字列として扱われます。`TRIM`（余分な空白を消す関数）で整えるか、入力規則で表記を統一してください。

### 数字が合っているのに差額が0にならない

小数を含む金額では、計算の誤差で差額が0にならないことがあります。円単位の整数なら起きにくいですが、気になるときは `E2` を `=ROUND(C2-D2,0)` にします。

### 範囲が足りなくなる

入金が増えて8行目を超えると、`SUMIF` の範囲に入りません。範囲を列全体（`入金一覧!$B:$B` と `入金一覧!$C:$C`）にすると、行が増えても対応できます。

## 振込手数料の差額を許容したいとき

見本の `INV-002` は、請求55,000円に対して54,450円の入金で、550円が不足しています。振込手数料を差し引いて振り込まれた場合などに起きます。手数料分を許容して消込済にするなら、`F2` の判定を次のように変えます。

```
=IF(D2=0,"未入金",IF(ABS(E2)<=550,"消込済",IF(E2>0,"不足あり","過入金")))
```

許容額（ここでは550円）はセルに出しておくと管理しやすくなります。手数料の扱いは取引先との取り決めや社内ルールで決まるため、差額の処理は自社の方針に従ってください。入金から日数が経った請求の管理は [売掛金の年齢調べ表](/hukugyou/posts/receivable-aging-table/) と組み合わせられます。

## よくある質問

### 請求番号がなく、金額だけで突き合わせることはできますか？

`COUNTIF` で入金額が請求額と一致するかを調べる方法はあります。ただし同じ金額の請求が複数あると誤って消し込むため、請求番号や取引先名の併用をおすすめします。

### 分割で入金された場合はどうなりますか？

`SUMIF` が同じ請求番号の入金を合計するので、そのまま対応できます。合計が請求額に達した時点で「消込済」になります。

### 会計ソフトの消込機能の代わりになりますか？

この見本は、一覧の突き合わせと状態判定をする簡易な仕組みです。仕訳の登録や帳簿への反映は含みません。実際の経理処理は、自社の会計の手順に従ってください。
