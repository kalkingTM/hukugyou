## 結論

深夜時間は、勤務時間と「0:00〜5:00」の重なり、勤務時間と「22:00〜翌5:00」の重なりを、それぞれ `MIN` と `MAX` で求めて足すと出せます。出勤が `B2`、退勤が `C2`、深夜の開始 22:00 が `H2`、終了 5:00 が `H3` にある場合の数式は次の1本です。

```
=ROUND((MAX(0,MIN((C2+(C2<B2)),$H$3)-B2)+MAX(0,MIN((C2+(C2<B2)),$H$3+1)-MAX(B2,$H$2)))*1440,0)/1440
```

見本ファイルでは、5日分の深夜時間の合計が13時間30分（小数で 13.5 時間）になります。

## 完成形

基準の深夜帯は `H2`（22:00）と `H3`（5:00）に入れてあります。

| 日 | 出勤 | 退勤 | 深夜時間 | 深夜(小数) |
|---|---|---|---|---|
| 11/2(月) | 9:00 | 18:00 | 0:00 | 0.00 |
| 11/3(火) | 13:00 | 23:30 | 1:30 | 1.50 |
| 11/4(水) | 17:00 | 2:00 | 4:00 | 4.00 |
| 11/5(木) | 22:00 | 6:00 | 7:00 | 7.00 |
| 11/6(金) | 4:00 | 9:00 | 1:00 | 1.00 |
| 合計 | | | 13:30 | 13.50 |

見本ファイルで動きを確認できます。

## 深夜時間を求める手順

### 1. 深夜帯を別のセルに入れる

`H2` に `22:00`、`H3` に `5:00` と入力します。数式に直接書かず、セルに出しておくと、深夜帯が違う職場でも値を変えるだけで済みます。

### 2. 退勤が翌日のときの扱いを決める

Excelは時刻を「1日＝1」の数字（シリアル値、Excelが日付や時刻を管理している数字）で持っています。退勤が出勤より小さい（例: 出勤 17:00、退勤 2:00）ときは、翌日にまたがっているので1日分を足します。それが次の部分です。

```
C2+(C2<B2)
```

`(C2<B2)` は、退勤が出勤より前の時刻なら 1、そうでなければ 0 を返します。

### 3. 2つの深夜帯との重なりを足す

深夜帯は、出勤した日の「0:00〜5:00」と「22:00〜翌5:00」の2つあります。

- `MAX(0,MIN(退勤,$H$3)-B2)`: 0:00〜5:00 と勤務時間の重なりです。早朝から働く日（11/6の4:00出勤）がここで拾われます。
- `MAX(0,MIN(退勤,$H$3+1)-MAX(B2,$H$2))`: 22:00〜翌5:00 と勤務時間の重なりです。`$H$3+1` は「翌日の5:00」を表します。
- `MIN` で勤務の終わりと深夜帯の終わりの早いほうを、`MAX` で勤務の始まりと深夜帯の始まりの遅いほうを取り、差を求めます。重ならないときは差がマイナスになるので、`MAX(0,…)` で0にします。
- 全体を `*1440` で分に直し、`ROUND(…,0)` で端数の誤差を消してから `/1440` で時刻に戻します。

`D` 列の表示形式は `h:mm` にします。

### 4. 合計を出す

`D7` に `=SUM(D2:D6)` を入れ、表示形式を `[h]:mm` にします。24時間を超える合計は `h:mm` では正しく表示されません。原因は [勤務時間の合計が24時間を超えると表示がずれる原因と直し方](/hukugyou/posts/work-hours-over-24h-display/) にあります。

## 深夜時間を小数（時間数）で出したい

給与計算などで 4.5 のような時間数が必要なときは、次の数式にします。

```
=ROUND(D2*24,2)
```

見本では11/5の深夜 7:00 が 7.00、合計が 13.50 になります。

## つまずきやすい点

- **日またぎの日が0:00になる**: 退勤を日付付きでなく時刻だけで入力していれば、`C2+(C2<B2)` の部分で翌日扱いになります。この部分を消していないか確認してください。
- **深夜時間が休憩を含んだままになる**: この数式は休憩を引いていません。休憩が深夜帯に入る日は、その分を別の列に入れて引いてください。休憩の引き方は [Excelで勤務時間から休憩を引いて実働時間を出す方法](/hukugyou/posts/work-hours-break-deduct/) を参照してください。
- **24時間以上続く勤務には対応しません**: この数式は、出勤から退勤までが24時間未満であることを前提にしています。
- **時刻が文字列になっている**: セルが左寄せで「22:00」と出ているときは文字列です。入力し直してください。

## 応用

### 深夜帯を変える

深夜帯が違う職場では、`H2` と `H3` を変えるだけで対応できます。

### 残業時間と組み合わせる

1日8時間を超えた分は [Excelで1日8時間を超えた残業時間だけを出す方法](/hukugyou/posts/overtime-over-8h-calc/) の数式で求められます。深夜と残業が重なる日の扱いは、職場の規則によります。

### 割増賃金は規則を確認する

この記事は「22時から5時の間に働いた時間」を数える方法の説明です。深夜の割増賃金の率や、どの時間が対象になるかは、労働基準法や就業規則、労働契約で決まります。個別の判断は、厚生労働省の情報や社内規定、社会保険労務士などの専門家に確認してください。

## よくある質問

### Excelで深夜時間を計算する数式は何ですか？

勤務時間と深夜帯の重なりを `MIN` と `MAX` で求めます。0:00〜5:00 の重なりと、22:00〜翌5:00 の重なりを足します。

### 日またぎ（夜勤）でも深夜時間は出せますか？

出せます。`C2+(C2<B2)` で退勤を翌日の時刻に直してから計算するので、17:00出勤・2:00退勤のような勤務でも 4:00 と求められます。

### 深夜時間の合計が24時間を超えると表示がおかしくなります

合計のセルの表示形式を `[h]:mm` にしてください。
