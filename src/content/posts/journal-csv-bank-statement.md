## 結論

通帳の明細は、入金なら「借方＝普通預金、貸方＝相手科目」、出金なら「借方＝相手科目、貸方＝普通預金」に並べ替えると仕訳の形になります。Excelでは `IF` で入金か出金かを見分け、金額を `入金額＋出金額` で1列にまとめれば、変換シートが作れます。

```
借方科目: =IF(明細!C2>0,"普通預金",明細!E2)
貸方科目: =IF(明細!C2>0,明細!E2,"普通預金")
金額　　: =明細!C2+明細!D2
```

見本ファイルでは6件の明細が6行の仕訳になり、借方と貸方の合計がどちらも 690,800円で一致します。完成した「仕訳」シートは、CSVとして保存できます。

## 通帳明細を仕訳の形にする手順

仕訳とは、お金の動きを「借方（左）」と「貸方（右）」に分けて書いた記録です。預金が増えるときは預金が借方、減るときは預金が貸方に来ます。

### 1. 明細シートに通帳の動きを貼る

「明細」シートに、日付・摘要・入金額・出金額を貼ります。入金のない行の入金額は空欄のままにします。`0` を入れても動きますが、空欄のほうが見やすくなります。

### 2. 相手科目を入れる

`E` 列に、その取引の相手側の勘定科目（売上高、地代家賃など）を入れます。科目をどれにするかは会社の処理方針しだいなので、ここは人が決めます。入力規則（プルダウン）にしておくと、表記ゆれを防げます。

### 3. 借方科目と貸方科目を入れる

「仕訳」シートの `B2` と `D2` に次の数式を入れ、下へコピーします。

```
=IF(明細!C2>0,"普通預金",明細!E2)
=IF(明細!C2>0,明細!E2,"普通預金")
```

入金額が0より大きければ入金なので、借方が「普通預金」、貸方が相手科目です。そうでなければ出金なので、左右が入れ替わります。通帳の預金科目名が「普通預金」でない場合は、文字列の部分を実際に使う科目名に置き換えます。

### 4. 金額と日付と摘要を入れる

```
=明細!C2+明細!D2
=C2
=TEXT(明細!A2,"yyyy/mm/dd")
=明細!B2
```

1行目が借方金額（`C2`）、2行目が貸方金額（`E2`）、3行目が日付（`A2`）、4行目が摘要（`F2`）です。入金額と出金額のどちらか一方しか入らないので、足せばその行の金額になります。`TEXT` は日付を「2026/11/02」のような文字に直す関数で、CSVにしたときに日付の見た目が崩れにくくなります。

### 5. 借方と貸方の合計を確かめる

最終行に `=SUM(C2:C7)` と `=SUM(E2:E7)` を入れ、一致することを確かめます。見本では、どちらも 690,800円です。一致しないときは、科目の入れ忘れではなく、金額の欄に文字（「1,000円」など）が入っていないかを疑います。

### 6. CSVとして保存する

「仕訳」シートを開いた状態で、「名前を付けて保存」から、ファイルの種類で「CSV（コンマ区切り）」または「CSV UTF-8」を選びます。CSVは、1つのシートだけを文字で保存する形式です。保存されるのは今開いているシートだけで、数式は結果の値になります。

## 会計ソフトに取り込む前に確かめること

CSVの列の並び・列名・日付の書き方・文字コード（UTF-8かShift_JISか）は、ソフトごとに決まりが違います。見本の列の並びは一例です。実際に使うソフトの公式ヘルプで取り込み形式を確かめ、その並びに合わせて「仕訳」シートの列を入れ替えてください。1〜2件だけで試しに取り込み、問題がなければ全件を取り込むと安全です。

## つまずきやすい点

- **借方と貸方の合計が合わない**: 金額が文字として入っています。セルが左寄せになっていないか確認し、数値に直してください。
- **科目が空欄のまま出る**: `E` 列の相手科目が未入力です。相手科目を入れ忘れた行は、借方か貸方が空欄になります。
- **CSVを開くと日本語が文字化けする**: 文字コードの違いです。保存時に「CSV UTF-8」とふつうの「CSV」を選び直して試してください。どちらが合うかは取り込み先の指定によります。
- **CSVを開くと日付が「2026/11/2」に変わる**: Excelでふたたび開いたときの自動表示で、ファイルの中身は変わっていません。メモ帳などで開いて確認できます。

## 応用

### 振込手数料のように1行を2つに分けたい

出金額に手数料が含まれる取引は、行を2つに分けて、「普通預金」と「支払手数料」を別々の金額で入れます。1行1仕訳の形のままにしておくと、取り込み側でも扱いやすくなります。

### 現金出納帳やカード明細にも使う

預金科目の文字列を「現金」や「未払金」に変えれば、同じ数式で他の明細にも使えます。入金・出金の列の意味が通帳と逆のカード明細は、列の対応を確かめてから使ってください。

## よくある質問

### 通帳の明細をそのまま会計ソフトに取り込めますか？

ソフトによっては明細の取り込み機能があります。使えない場合や、科目を自分で決めたい場合は、この記事のように仕訳の形に直してCSVで取り込む方法があります。対応状況は、使っているソフトの公式ヘルプで確認してください。

### 仕訳CSVの列の並びは決まっていますか？

ソフトごとに決まっています。見本の「日付・借方科目・借方金額・貸方科目・貸方金額・摘要」は一例です。取り込み先のヘルプにある形式に合わせて、列を入れ替えてください。

### 相手科目は自動で入れられますか？

摘要の文字をもとに自動で振り分ける方法もありますが、この見本は人が決める前提です。判定の誤りを防ぐため、最初は手で入れて確認することをおすすめします。
