## 結論

精算表は、「試算表＋修正記入」の金額を足し引きした残高を、勘定科目の区分（資産・負債・純資産・収益・費用）に応じて損益計算書の欄か貸借対照表の欄へ振り分ける表です。Excelでは、`IF` 関数と `MAX` 関数の組み合わせで、この振り分けを自動にできます。

精算表（決算のとき、試算表から財務諸表への流れを1枚の表で確かめるための表）の全体像を、手を動かして確認する用途を想定しています。見本ファイルの数字は、すべて自作の架空のものです。

修正記入には、次の3つの決算整理仕訳（決算のときに金額を整える仕訳）を入れています。

- 貸倒引当金の設定：売掛金の回収できないかもしれない見込み額3,000円を、繰入として費用にする

## 精算表の作り方

### 1. 行と列を並べる

A列に勘定科目、B列に区分（資産・負債・純資産・収益・費用）、C〜D列に試算表の借方・貸方、E〜F列に修正記入の借方・貸方、G〜H列に損益計算書、I〜J列に貸借対照表を置きます。B列の「区分」が、あとで振り分けの判断に使われます。

決算整理で新しく出てくる科目（見本ファイルでは減価償却費と貸倒引当金繰入）も、試算表の金額は空欄のまま、行を作っておきます。

### 2. 試算表と修正記入の金額を入れる

試算表の借方・貸方は、そのまま転記します。修正記入は、決算整理仕訳の借方と貸方を、それぞれ該当科目の行に入れます。入力したら、まず合計行で試算表どうし、修正記入どうしの借方と貸方が一致することを確かめます。

### 3. 損益計算書と貸借対照表の欄に数式を入れる

3行目（現金の行）の `G3` から `J3` に、次の4つの数式を入れ、下の行へコピーします。

`G3`（損益計算書の借方）

```
=IF(OR($B3="収益",$B3="費用"),MAX(C3+E3-D3-F3,0),0)
```

`H3`（損益計算書の貸方）

```
=IF(OR($B3="収益",$B3="費用"),MAX(D3+F3-C3-E3,0),0)
```

`I3`（貸借対照表の借方）

```
=IF(OR($B3="収益",$B3="費用"),0,MAX(C3+E3-D3-F3,0))
```

`J3`（貸借対照表の貸方）

```
=IF(OR($B3="収益",$B3="費用"),0,MAX(D3+F3-C3-E3,0))
```

部品ごとの意味です。

- `C3+E3-D3-F3`: 借方（試算表＋修正）から貸方（試算表＋修正）を引いた残高です。プラスなら借方残高です。
- `MAX(...,0)`: 負の値を0にします。借方に出る金額と貸方に出る金額が、同時に出ないようにします。
- `OR($B3="収益",$B3="費用")`: 区分が収益か費用なら「真」を返します。真なら損益計算書の欄、偽なら貸借対照表の欄に金額が入ります。
- `$B3`: 列だけを固定しているので、右へも下へもコピーできます。

### 4. 当期純利益と合計を出す

当期純利益は、損益計算書の貸方合計（収益）から借方合計（費用）を引いた差額です。見本ファイルでは17行目に次の数式を入れています。

```
G17: =MAX(SUM(H3:H16)-SUM(G3:G16),0)
H17: =MAX(SUM(G3:G16)-SUM(H3:H16),0)
I17: =H17
J17: =G17
```

利益が出たときは、`G17`（損益計算書の借方）と `J17`（貸借対照表の貸方）に同じ金額が入ります。損失のときは反対側に入るので、赤字でも同じ表が使えます。18行目の合計は `=SUM(G3:G17)` のように、17行目までを足します。

### 5. 一致しているかを自動で確かめる

表の下に、次のような確認用のセルを置いておくと、入力ミスにすぐ気づけます。

```
=IF(AND(G18=H18,I18=J18),"一致","不一致")
```

損益計算書どうし、貸借対照表どうしの合計が両方一致すれば「一致」です。

## 合計が合わないときは

### 試算表の段階で借方と貸方が違う

精算表の左端である試算表の合計が一致していないと、先へ進んでも合いません。転記漏れや、借方と貸方の入れ違いを先に探します。

### 修正記入の借方と貸方が同じ行数・同じ金額になっていない

決算整理仕訳は、必ず借方と貸方の金額が同じになります。修正記入の合計が一致していなければ、片側の入れ忘れです。

### 区分が間違っていて、別の欄に入っている

「減価償却費」を資産にしてしまうと、費用なのに貸借対照表へ振り分けられます。B列の区分を見直してください。区分の入力は、データの入力規則でプルダウンにしておくと防げます。

### 貸倒引当金は、評価勘定の扱いに注意

見本ファイルでは、貸倒引当金は区分を「資産」にして、貸借対照表の貸方に出しています。実際の貸借対照表では売掛金から差し引く形で表示されることが多いので、試験や実務の書式に合わせて見直してください。

## 応用：行を増やしたいとき

科目が増えるときは、合計行（18行目）の上に行を挿入し、数式を上の行からコピーします。合計の `SUM` の範囲は、挿入した行を含めて自動で広がります。ただし、一番下の行の下に追加すると範囲に入らないので、必ず途中に挿入してください。

## よくある質問

### 精算表は必ず作らないといけませんか？

作成が決まっているわけではなく、試算表から決算書をまとめる流れを整理する補助の表です。会社や学習の場面によって、使う・使わないが分かれます。

### 精算表の8つの欄は、どう読めばよいですか？

試算表・修正記入・損益計算書・貸借対照表の4つに、それぞれ借方と貸方があり、合わせて8つの欄です。左から右へ、残高が決算書の形に整理されていきます。

### Excelの数式ではなく手計算で確認したいときは？

見本ファイルの黄色い欄に自分の数字を入れ、自分で出した残高と数式の結果を見比べると、確認の練習になります。個別の会計処理や税務上の判断は、税理士などの専門家に相談してください。
