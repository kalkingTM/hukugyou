## 結論

勤務時間が `8:00` のような時刻形式のセルに、時給をそのまま掛けると金額が小さくなります。時間のセルは「1日＝1」の数字で持たれているためで、**24を掛けて「時間数」に直してから**時給を掛けると正しい金額になります。

```
=ROUNDDOWN(ROUND(E2*1440,0)*$J$2/60,0)
```

`E2` が実働時間、`J2` が時給です。見本ファイルでは、時給1,150円で5日分の合計が36,416円になります。

「誤」の列は、`=E2*$J$2` とした場合の結果です。8時間働いて383円になってしまいます。見本ファイルで動きを確認できます。

## 勤務時間に時給を掛けると金額が小さくなる原因

Excelは時刻を、1日を「1」とする数字（シリアル値、Excelが日付や時刻を管理している数字）で持っています。`8:00` は1日の3分の1なので、中身は約 0.3333 です。これに時給1,150を掛けると 383.33 になります。

つまり、掛けているのは「8時間」ではなく「0.3333日」です。1日は24時間なので、次のどちらかで時間数に直します。

- **24を掛ける**: `E2*24` は 8 になります。
- **1440を掛ける**: `E2*1440` は分（480）になります。60で割れば時間数です。

## 日給を正しく出す手順

### 1. 時給を別のセルに入れる

`J2` に時給（1150）を入力します。数式に金額を直接書かず、セルに出しておくと、時給が変わったときに1か所直すだけで済みます。

### 2. 実働時間を出す

`E2` に次の数式を入れます。退勤から出勤を引き、休憩（`D2` に分で入力）を引いた時間です。

```
=ROUND(((C2-B2)*1440-D2),0)/1440
```

`(C2-B2)*1440` で勤務時間を分に直し、休憩の分を引いて、1440で割って時刻に戻しています。`ROUND` は、小数の誤差で1分ずれるのを防ぎます。表示形式は `h:mm` にします。休憩の引き方の詳細は [勤務時間から休憩を引いて実働時間を出す方法](/hukugyou/posts/work-hours-break-deduct/) を参照してください。

### 3. 日給を出す

`G2` に次の数式を入れ、下にコピーします。

```
=ROUNDDOWN(ROUND(E2*1440,0)*$J$2/60,0)
```

- `E2*1440` で、実働時間を分にします。
- `ROUND(…,0)` で、分の小数の誤差を消します。
- `*$J$2/60` で、1分あたりの時給を掛けます。
- `ROUNDDOWN(…,0)` で、1円未満を切り捨てます。

5:20（320分）は 320×1150÷60＝6133.33 となり、切り捨てて 6,133円です。

### 4. 合計を出す

`E7` に `=SUM(E2:E6)`、`G7` に `=SUM(G2:G6)` を入れます。`E7` の表示形式は `[h]:mm` にしてください。24時間を超える合計は `h:mm` では正しく表示されません。原因は [勤務時間の合計が24時間を超えると表示がずれる原因と直し方](/hukugyou/posts/work-hours-over-24h-display/) にあります。

## つまずきやすい点

- **金額が小数のまま残る**: `ROUNDDOWN` を付けていないと、6133.333… のように表示されます。表示形式で見た目だけ整えても、合計では小数が足されるので、数式で丸めてください。
- **`=E2*24*J2` で端数が出る**: 5:20 は 5.3333… 時間なので、時給を掛けた結果にごく小さな誤差が出て、切り捨てで1円ずれることがあります。分に直してから計算する今回の数式なら、この誤差を避けられます。
- **時刻が文字列になっている**: セルが左寄せの `8:00` なら文字列です。入力し直してください。
- **日またぎの勤務で負の値になる**: 退勤が出勤より前の時刻だと、`C2-B2` はマイナスになります。この場合は `C2-B2+(C2<B2)` に変えます。

## 応用

### 端数を四捨五入や切り上げにしたい

`ROUNDDOWN` を `ROUND`（四捨五入）や `ROUNDUP`（切り上げ）に変えます。賃金の端数処理は、法令や就業規則に決まりがある場合があります。実際にどちらにするかは、職場の規則を確認し、個別の判断は専門家に確認してください。

### 時間数（小数）の表を別に作る

給与計算などで 7.5 のような時間数が必要なときは、次の数式です。

```
=ROUND(E2*24,2)
```

11/3 の実働 7:30 が 7.50 になります。

### 深夜や残業の時間を足す

1日8時間を超えた分は [1日8時間を超えた残業時間だけを出す方法](/hukugyou/posts/overtime-over-8h-calc/)、22時以降の分は [深夜時間（22時〜5時）を計算する方法](/hukugyou/posts/night-hours-22-to-5/) で別の列に出せます。割増の率や対象は、職場の規則によります。

## よくある質問

### Excelで時間に時給を掛けると、なぜ金額が合わないのですか？

時間のセルは「1日＝1」の数字で持たれているためです。24を掛けて時間数に直してから時給を掛けると合います。

### 時給の計算は ×24 と ×1440 のどちらがよいですか？

どちらでも計算できますが、分（×1440）に直してから `ROUND` で整数にすると、小数の誤差による1円のずれを避けられます。

### 8:00 を 8 という数字に変えるには？

`=E2*24` と入力します。表示形式が時刻のままだと 8:00 と表示されるので、セルの表示形式を「標準」または「数値」に変えてください。
