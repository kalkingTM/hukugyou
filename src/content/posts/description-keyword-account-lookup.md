## 結論

摘要の文字から勘定科目を自動で入れるには、別シートに「キーワードと勘定科目の対応表」を作り、摘要が `B2` にあるとき次の1本の数式で引きます。

```
=IFERROR(INDEX(科目表!$B$2:$B$11,MATCH(1,INDEX(--ISNUMBER(SEARCH(科目表!$A$2:$A$11,B2)),0),0)),"要確認")
```

摘要にキーワードが含まれる行を上から探し、最初に見つかった行の勘定科目を返します。どれにも当てはまらない摘要は「要確認」と表示されるので、そこだけ人が決めれば済みます。見本ファイルは、この数式を8件の明細に入れたものです。

## 振り分けた結果の完成形

見本ファイルの「明細」シートです。「勘定科目(自動)」と「一致したキーワード」が数式で入ります。

|---|---|---|---|---|

| 2026/11/5 | 事務所家賃 11月分 | 110,000 | 地代家賃 | 家賃 |
| 2026/11/10 | 文具店 事務用品 | 8,800 | 消耗品費 | 文具 |

## 作り方

### 1. キーワードと勘定科目の対応表を作る

「科目表」シートの `A列` にキーワード、`B列` に勘定科目を入れます（`A1` と `B1` は見出し）。見本では2行目から11行目に10組を入れています。

| キーワード | 勘定科目 |
|---|---|
| 売上 | 売上高 |
| 家賃 | 地代家賃 |
| 文具 | 消耗品費 |
| 事務用品 | 消耗品費 |
| 電気 | 水道光熱費 |

（以下、水道・電話・通信・振込手数料・切手が続きます。）同じ勘定科目に対して、キーワードを複数並べてかまいません。

どの勘定科目を使うかは、会社の処理方針しだいです。この表は自社の方針に合わせて、人が決めて入れてください。

### 2. 摘要からキーワードを探す

次の部分が、摘要の中にキーワードがあるかを調べます。

```
SEARCH(科目表!$A$2:$A$11,B2)
```

`SEARCH` は、文字列の中で指定した文字が何文字目にあるかを返す関数で、見つからないと `#VALUE!` というエラーを返します。キーワードの範囲をまとめて渡すと、10個のキーワードそれぞれについて結果が10個並びます。

### 3. 見つかったかどうかを 1 と 0 にする

```
--ISNUMBER(...)
```

`ISNUMBER` は、数字なら TRUE、エラーなら FALSE を返します。その前の `--` で TRUE を 1、FALSE を 0 に変えています。これで「見つかった行が 1」の並びになります。

### 4. 最初に見つかった行の勘定科目を取り出す

```
=INDEX(科目表!$B$2:$B$11, MATCH(1, 1と0の並び, 0))
```

`MATCH(1, …, 0)` は、並びの中で最初に1が出てくる位置を返します。`INDEX` は、その位置にある勘定科目を引いてくる関数です。内側の `INDEX(…,0)` は、古いExcelでも `Ctrl+Shift+Enter` を使わずに配列として計算させるための書き方です。

### 5. 見つからないときは「要確認」にする

どのキーワードにも当てはまらないと `MATCH` は `#N/A` を返します。`IFERROR` で包むと、エラーの代わりに「要確認」と表示できます。`IFERROR(A, B)` は「Aがエラーなら B を表示する」関数です。

### 6. 一致したキーワードも出して確認する

`E2` に、勘定科目の代わりにキーワードを引く数式を入れます。

```
=IFERROR(INDEX(科目表!$A$2:$A$11,MATCH(1,INDEX(--ISNUMBER(SEARCH(科目表!$A$2:$A$11,B2)),0),0)),"")
```

どの言葉で判定されたかが見えるので、思わぬ振り分けに気づきやすくなります。

### 7. 要確認の件数を数える

明細の下に、次の数式で件数を出しておきます。見本では1件です。

```
=COUNTIF(D2:D9,"要確認")
```

0件になるまで、科目表への追加か、手での入力を続けます。

## 数式がうまく動かないとき

### すべて「要確認」になる

キーワードの範囲の指定ずれが多い原因です。`科目表!$A$2:$A$11` が、キーワードの入った行だけを囲んでいるか確認します。範囲に空白のセルが含まれていると、空白は「どの摘要にも含まれる」扱いになり、先頭の行の勘定科目が全件に入ってしまうので注意してください。

### 意図しない科目になる

「電気」は「電気工事」にも含まれます。1つのキーワードが複数の取引に当てはまるときは、より具体的な言葉（「電気料金」など）を表の上のほうに置きます。同じ摘要に複数のキーワードが入る場合は、表の上にあるものが優先されるためです。

### 全角・半角で一致しない

`SEARCH` は、アルファベットの大文字・小文字は区別しませんが、全角と半角は区別します。通帳の摘要が半角カナで出力されるときは、キーワードも半角カナで入れるか、`JIS` 関数で全角にそろえてから探します。

### 数式を入れてから表を増やしたとき

キーワードを表の末尾に足したのに反映されないときは、数式の範囲が古いままです。範囲を広めに取るか、表を「テーブル」に変換すると、追加が反映されやすくなります。ただし、広めに取った範囲に空白行があると、前述のとおり全件が先頭の科目になるので、空白を含めないよう注意してください。

## 判定の条件を変えたいとき

- **金額で分けたい**: 同じ摘要でも金額で科目が変わるなら、キーワード判定のあとに `IF` で条件を足します。たとえば `=IF(C2>=100000,"要確認",…)` のように、高額な行は人の確認に回せます。
- **入金と出金を分けたい**: 「入金額」「出金額」の列があるときは、出金の行だけに判定をかける形にします。明細を仕訳の形にそろえる方法は、[通帳明細を仕訳の形に変換する方法](/hukugyou/posts/journal-csv-bank-statement/)で扱っています。

## 判定結果の扱いについての注意

キーワードによる振り分けは、摘要の文字だけで機械的に決めるものです。実際の取引の内容によって、適切な勘定科目は変わることがあります。自動で入った科目は必ず目で確認し、処理の判断に迷うときは税理士などの専門家に確認してください。

請求と入金の突き合わせを行うときは、[入金消込の方法](/hukugyou/posts/payment-reconcile-match/)も参考になります。

## よくある質問

### 摘要の一部にキーワードが含まれていれば判定できますか？

できます。`SEARCH` は摘要の途中に含まれていても見つけるので、「事務所家賃 11月分」でも「家賃」で一致します。

### キーワードが複数に当てはまるときはどうなりますか？

科目表の上にあるキーワードが優先されます。見本の最後の行は「売上」と「振込手数料」の両方を含みますが、「売上」が上にあるので売上高になります。

### Excel 2016 など古いバージョンでも使えますか？

この数式で使う `SEARCH`、`INDEX`、`MATCH`、`IFERROR`、`ISNUMBER` は、古いExcelにもある関数です。新しい関数は使っていません。
