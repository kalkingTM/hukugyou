## 結論

勤務時間の合計が24時間を超えて表示がずれるときは、合計のセルの表示形式を `h:mm` から `[h]:mm`（角かっこ付き）に変えれば直ります。数式は `=SUM(B2:B7)` のままで構いません。

見本ファイルでは、6日分の実働時間の合計が52時間20分です。表示形式が `h:mm` のままだと、これが「4:20」と表示されます。数式の値は正しく、24時間ごとに「1日」へ繰り上がった余りだけが見えている状態です。

## 完成形

見本ファイルの `B` 列に、6日分の実働時間が入っています。

| 日 | 実働時間 |
|---|---|
| 11/2(月) | 8:00 |
| 11/3(火) | 8:30 |
| 11/4(水) | 9:15 |
| 11/5(木) | 7:45 |
| 11/6(金) | 10:00 |
| 11/7(土) | 8:50 |

合計の出し方を4通り並べると、次のようになります。

| 合計の出し方 | 結果 |
|---|---|
| 表示形式 `h:mm`（ずれる） | 4:20 |
| 表示形式 `[h]:mm`（正しい） | 52:20 |
| 小数の時間 | 52.33 |
| 文字列「○時間○分」 | 52時間20分 |

時給 1,200 円のときの金額は 62,800 円です。見本ファイルで動きを確認できます。

## 合計が24時間を超えて4:20になるのはなぜ？

Excelは時刻を「1日＝1」とする数字（シリアル値）で持っています。1時間は 1/24、52時間20分は約 2.1806（2日と4時間20分）です。表示形式 `h:mm` は「日」の部分を捨てて時と分だけを見せるため、2日分が消えて「4:20」になります。

つまり計算が間違っているのではなく、見せ方の問題です。表示形式を変えるだけで、数式は触らずに直せます。

## 合計を52:20と表示する手順

### 1. 合計のセルを選ぶ

合計の数式（例: `=SUM(B2:B7)`）が入っているセルを選びます。

### 2. 表示形式を `[h]:mm` にする

1. `Ctrl` + `1` を押してセルの書式設定を開きます。
2. 「表示形式」タブで「ユーザー定義」を選びます。
3. 「種類」の欄に `[h]:mm` と入力して OK を押します。

角かっこ `[ ]` は「24時間で区切らず、時間数をそのまま表示する」という指定です。`[h]:mm` はExcelの古いバージョンから使えます。

## 合計を小数の時間（52.33）で出したい

時給や日給の計算に使うなら、時間を小数にします。

```
=ROUND(SUM(B2:B7)*24,2)
```

時刻の値に 24 を掛けると、時間数になります。`ROUND` で小数第2位に丸めているのは、`52.3333…` のような割り切れない値を整えるためです。表示形式は「標準」か `0.00` にします。

## 合計を「52時間20分」の文字で出したい

請求書やメールの文面に貼る文字列が必要なときは、分に直してから時間と分に分けます。

```
=INT(ROUND(SUM(B2:B7)*1440,0)/60)&"時間"&MOD(ROUND(SUM(B2:B7)*1440,0),60)&"分"
```

- `SUM(B2:B7)*1440`: 合計を分に直します（1日は1440分です）。
- `ROUND(…,0)`: 秒の誤差を丸めて、整数の分にします。
- `INT(…/60)`: 分を60で割った整数部分が、時間です。
- `MOD(…,60)`: 60で割った余りが、分です。
- `&`: 文字をつなげる記号です。

結果は文字列なので、このセルを足し算には使えません。表示専用にしてください。

## つまずきやすい点

- **`[h]:mm` にしたのに 4:20 のまま**: 数式が入っているセルではなく、別のセルの表示形式を変えていないか確認します。合計を別のセルに参照している場合は、そのセルにも `[h]:mm` が必要です。
- **合計が `########` になる**: 列幅が足りません。列の境目をダブルクリックして広げます。
- **合計が 0:00 のまま**: 実働時間が文字列になっている可能性があります。左寄せで表示される「8:00」は文字列のことがあり、`SUM` は文字列を無視します。入力し直してください。
- **時給を掛けたら金額が合わない**: `[h]:mm` で表示した値に時給を直接掛けると、約24分の1の金額になります。`×24` で時間数にしてから掛けます。

## 応用

### 時給を掛けて金額を出す

時給が `E7` にあるときの金額は、次の数式です。

```
=ROUND(SUM(B2:B7)*24*E7,0)
```

見本では 52時間20分 × 1,200 円で、62,800 円になります。小数に丸めた 52.33 に時給を掛けると 62,796 円となり、4円ずれます。金額には丸める前の合計を使ってください。

### 実働時間そのものの出し方を知りたい

出勤・退勤・休憩から日ごとの実働時間を出す方法は、[Excelで勤務時間から休憩を引いて実働時間を出す方法](/hukugyou/posts/work-hours-break-deduct/)で扱っています。

### 賃金の端数処理は職場の規則を確認する

勤務時間の端数をどう扱うか、賃金をどう計算するかは、会社の就業規則や労働契約によって異なります。この記事は時間を計算して表示する方法の説明で、賃金や労働時間の判断はできません。必要な場合は厚生労働省の情報や社内規定、専門家に確認してください。

## よくある質問

### 24時間を超える合計を表示する形式は何ですか？

`[h]:mm` です。時間を角かっこで囲むと、24時間で繰り上げずに、52:20 のように時間数をそのまま表示します。

### 合計の数式を変えないと直りませんか？

数式は変えなくて構いません。`=SUM(B2:B7)` の値は正しく、表示形式だけを `[h]:mm` に変えれば直ります。

### 月の合計が100時間を超えても使えますか？

使えます。`[h]:mm` は24時間に限らず、100時間でも1000時間でもそのまま表示します。
