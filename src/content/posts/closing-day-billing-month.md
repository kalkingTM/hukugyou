## 結論

取引日が `A2`、締め日（20日締めなら20）が `H1` にあるとき、何月分の請求かは次の1本で出せます。結果はその月の1日の日付で返り、表示形式を「yyyy年m月分」にすれば「2026年11月分」のように見えます。

```
=DATE(YEAR(A2),MONTH(A2)+(DAY(A2)>$H$1),1)
```

取引日の「日」が締め日を超えていれば翌月、超えていなければ同じ月、と判定する式です。月末締めなら `H1` に31を入れれば、同じ式のまま使えます。

## 20日締めの判定結果の完成形

見本ファイルの内容です。締め日は20日、取引日が20日までなら同じ月、21日以降なら翌月の請求になります。

| 取引日 | 取引先 | 金額 | 請求月の表示 |
|---|---|---|---|
| 2026/10/20 | A社 | 100,000 | 2026年10月分 |
| 2026/10/21 | A社 | 50,000 | 2026年11月分 |
| 2026/10/31 | B社 | 30,000 | 2026年11月分 |
| 2026/11/5 | B社 | 20,000 | 2026年11月分 |
| 2026/11/20 | A社 | 40,000 | 2026年11月分 |

10/20は締め日ちょうどなので10月分、翌日の10/21から11月分です。12/21は年をまたぎ、2027年1月分になります。見本ファイルで動きを確認できます。

## 作り方

### 1. 締め日を入れるセルを決める

見本ファイルでは `H1` に20と入れています。締め日を数式に直接書かず1か所にまとめると、25日締めなどに変わったときも、このセルを書き換えるだけで済みます。

### 2. 請求月を出す

`D2` に次の数式を入れ、下へコピーします。

```
=DATE(YEAR(A2),MONTH(A2)+(DAY(A2)>$H$1),1)
```

- `YEAR(A2)` と `MONTH(A2)`: 取引日の年と月です。
- `DAY(A2)>$H$1`: 取引日の「日」が締め日より大きければ1、そうでなければ0になります（条件が成り立つと1として足し算に使えます）。
- `DATE(年, 月, 1)`: 年・月・1日から日付を作る関数です。月が13になっても、自動で翌年の1月として扱われます。だから12/21は2027/1/1になります。
- `$H$1`: 下へコピーしても締め日のセルがずれないよう、`$` で固定しています。

### 3. 「○年○月分」の見た目にする

`D2` のセルを選び、セルの書式設定の「ユーザー定義」に次を入れます。

```
yyyy"年"m"月分"
```

中身は日付のまま、見た目だけが「2026年11月分」になります。日付のままなので、あとで集計や並べ替えに使えます。文字として取り出したいときは、`E2` に次の数式を入れます。

```
=TEXT(D2,"yyyy年m月分")
```

### 4. 月ごとの請求額を合計する

別の場所に請求月（各月の1日）を並べ、次の数式で合計します。`G4` に請求月、`H4` に合計を出す場合です。

```
=SUMIF($D$2:$D$9,G4,$C$2:$C$9)
```

`SUMIF` は、条件に合う行の金額だけを足す関数です。請求月の列（D列）が `G4` と同じ行の、金額（C列）を足します。請求月を日付で持たせてあるので、条件がぴったり一致します。売掛金が何日たっているかを調べる表は、[売掛金の年齢調べの表の作り方](/hukugyou/posts/receivable-aging-table/)で扱っています。

## 数式がうまく動かないとき

### 請求月が数字（46327など）で表示される

セルの表示形式が日付になっていません。手順3のユーザー定義の形式を設定します。

### 判定が1日ずれる、締め日の日が逆になる

`>` を `>=` にしていないか確認します。締め日ちょうどの取引は、その月の請求に入れるため、`>` が正しい形です。会社の取り決めで「締め日当日は翌月」とするときだけ `>=` にします。

### #VALUE! と表示される

取引日が文字として入っています。「2026.10.20」のようにドットで区切ると日付になりません。「2026/10/20」の形に入れ直します。

### 月ごとの合計が0になる

集計表の請求月が、各月の1日の日付になっているか確認します。「11月」と文字で入れると、D列の日付と一致しません。

## 条件を変えたいとき

- **取引先ごとに締め日が違う**: 取引先と締め日の対応表を作り、`H1` の代わりに `VLOOKUP` で締め日を引いてきます。たとえば `=DATE(YEAR(A2),MONTH(A2)+(DAY(A2)>VLOOKUP(B2,$J$2:$K$10,2,FALSE)),1)` です。
- **請求月ではなく締め日そのものを出したい**: 請求月の1日を求めたあと、`=D2+MIN($H$1,DAY(EOMONTH(D2,0)))-1` とすると、その月の締め日の日付になります。締め日から支払予定日を出す方法は、[支払予定日を出す方法](/hukugyou/posts/payment-due-date-eomonth/)で説明しています。

## 取引条件の扱いについての注意

締め日や、締め日当日の取引をどちらの月に入れるかは、取引先との契約や取引条件で決まります。この記事は計算方法の説明であり、個別の取引の扱いは契約の内容に従ってください。

## よくある質問

### 20日締めの請求月を求める数式はどう書きますか？

取引日が `A2` なら `=DATE(YEAR(A2),MONTH(A2)+(DAY(A2)>20),1)` です。20日までなら同じ月、21日以降なら翌月の1日が返ります。

### 月末締めの場合は同じ式を使えますか？

使えます。締め日のセルに31を入れると、どの月でも「日」が31を超えないため、請求月は常に取引日と同じ月になります。

### 12月の取引が翌年1月分になるとき、年は自動で変わりますか？

変わります。`DATE` 関数は、月が13になると翌年の1月として扱うので、年の計算を別に書く必要はありません。
