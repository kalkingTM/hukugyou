## 結論

生年月日から満年齢を出すには、`DATEDIF` 関数（2つの日付の間の年・月・日数を数える関数）を使います。生年月日が `B2`、基準日が `J2` にある場合の数式は次の1本です。

```
=DATEDIF(B2,$J$2,"Y")
```

基準日を `=TODAY()`（今日の日付を返す関数）にすれば、開くたびに今日時点の年齢になります。見本ファイルでは、基準日を2026年11月21日に固定して、結果が毎回同じになるようにしています。

## 満年齢を出す手順

### 1. 基準日をセルに入れる

`J2` に基準日を入力します。数式に日付を直接書かず、セルに出しておくと、「4月1日時点の年齢」のように基準日を変えたいときも `J2` を書き換えるだけで済みます。今日時点にしたいときは `J2` に `=TODAY()` と入れます。

### 2. 満年齢を出す

`C2` に次の数式を入れ、下へコピーします。

```
=DATEDIF(B2,$J$2,"Y")
```

- `B2`: 開始日（生年月日）です。
- `$J$2`: 終了日（基準日）です。`$` を付けて固定しているので、下へコピーしても `J2` のままになります。
- `"Y"`: 満の年数を返す指定です。誕生日が来るまでは1年に数えません。

`DATEDIF` は、関数の入力候補には出ませんが、最後まで手で入力すれば使えます。開始日が終了日より後だと `#NUM!` エラーになります。

### 3. 「36歳7ヶ月」の形で表示する

`D2` に次の数式を入れます。

```
=DATEDIF(B2,$J$2,"Y")&"歳"&DATEDIF(B2,$J$2,"YM")&"ヶ月"
```

`"YM"` は、満の年数を除いた残りの月数を返す指定です。`&` は文字をつなぐ記号で、数字と「歳」「ヶ月」を1つの文字にします。

### 4. 次の誕生日までの日数を出す

`E2` に次の数式を入れ、表示形式を日付にします。

```
=EDATE(B2,12*(C2+1))
```

`EDATE` は、日付から指定した月数だけ先の日付を返す関数です。生年月日に「満年齢＋1」年分（12ヶ月×回数）を足すと、次の誕生日になります。`F2` は `=E2-$J$2` で、その日までの日数が出ます。田中さんは145日です。

## 365で割ると年齢がずれる理由

「（基準日−生年月日）÷365」を切り捨てる方法は、うるう年（2月29日がある年）の分だけ日数が増えるので、誕生日の直前にずれます。山本さん（1990/11/25生まれ）は、誕生日の4日前なので正しくは35歳です。ところが日数は13,145日あり、`INT(13145/365)` は36になります。

```
=INT(($J$2-B7)/365)
```

見本ファイルの `G` 列にこの数式を入れてあります。年齢の計算には使わず、`DATEDIF` を使ってください。

## 数式がうまく動かないとき

### #NUM! と表示される

生年月日が基準日より後の日付になっています。入力ミス（年の入れ間違いなど）がないか確認します。

### #VALUE! と表示される

生年月日が文字として入っています。「1990.4.15」のようにドットで区切ると日付になりません。「1990/4/15」の形で入れ直します。左揃えになっているセルは、文字の疑いがあります。

### 年齢が「36.6」のような数字や日付で表示される

表示形式が合っていません。`C` 列は「標準」か「数値」にします。

## 基準日や表示を変えたいとき

- **4月1日時点の年齢**: `J2` に `2027/4/1` のように入力します。
- **和暦の生年月日を扱う**: セルの表示形式を和暦にしても、中身は同じ日付なので、同じ数式で計算できます。
- **年齢で絞り込む**: 満年齢の列を使って、`=COUNTIF(C2:C7,">=30")` のように人数を数えられます。日付の横に曜日も出したいときは、[日付の横に曜日を自動で表示する方法](/hukugyou/posts/date-weekday-auto-display/) を参照してください。

## 年齢の扱いについての注意

この記事はExcelでの計算方法の説明です。年齢の数え方が契約や制度の条件になる場合（加入条件・受給条件など）、基準日や数え方の定めは個別に異なります。判断が必要なときは、該当する制度の公式の案内を確認し、個別の判断は専門家に相談してください。

## よくある質問

### DATEDIF関数が候補に出ないのですが、使えますか？

使えます。入力候補には出ませんが、`=DATEDIF(` から手で最後まで入力すれば計算されます。

### 今日の日付で自動更新するにはどうしますか？

基準日のセルに `=TODAY()` を入れます。ファイルを開くたびに今日の日付で再計算されるので、日付を固定したい書類には向きません。

### 生年月日から「何歳何ヶ月」を出すには？

`=DATEDIF(B2,$J$2,"Y")&"歳"&DATEDIF(B2,$J$2,"YM")&"ヶ月"` と入力します。田中さん（1990/4/15生まれ）は、2026/11/21時点で36歳7ヶ月になります。
