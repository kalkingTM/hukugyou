## 結論

売掛金の年齢調べ（エイジング）は、「基準日 − 請求日」で経過日数を出し、`IF` で30日・60日・90日の区分に分け、`SUMIF` で区分ごとの金額を合計すると作れます。請求日が `C2`、基準日が `$I$1` にある場合の数式は次の2本です。

```
=$I$1-C2
=IF(E2<=30,"30日以内",IF(E2<=60,"31〜60日",IF(E2<=90,"61〜90日","90日超")))
```

見本ファイルでは、基準日 2026/11/30 時点の未入金8件、合計 958,000円が区分ごとに集計されます。

## 年齢調べ表の作り方

年齢調べとは、まだ入金されていない売掛金を「請求してから何日たっているか」で分けて、回収が遅れているものを見つける表です。

### 1. 基準日を1つのセルに入れる

`I1` に集計したい日（例: 月末日の 2026/11/30）を入力します。数式に日付を直接書かず、セルに出しておくと、月が変わっても値を1か所変えるだけで済みます。常に今日の日付で見たいときは、`I1` を `=TODAY()` にします。

### 2. 経過日数を求める

`E2` に次の数式を入れ、下へコピーします。

```
=$I$1-C2
```

Excelは日付を「1900年1月1日からの日数」という数字（シリアル値）で持っているので、日付どうしを引くと日数になります。`$I$1` の `$` は、コピーしても基準日の位置がずれないようにする印（セルの固定）です。`E` 列の表示形式は「標準」または「数値」にします。日付の形式のままだと、日数が日付で表示されます。

### 3. 区分を自動で付ける

`F2` に次の数式を入れ、下へコピーします。

```
=IF(E2<=30,"30日以内",IF(E2<=60,"31〜60日",IF(E2<=90,"61〜90日","90日超")))
```

条件を上から順に調べ、最初に当てはまった区分を返します。境目の日は小さいほうの区分に入ります。見本では経過日数ちょうど30日の A-005 は「30日以内」、ちょうど90日の A-006 は「61〜90日」です。

### 4. 区分ごとの件数と金額を集計する

`H5:H8` に区分名を入れ、件数は `I5`、金額は `J5` に次の数式を入れて下へコピーします。

```
=COUNTIF($F$2:$F$9,H5)
=SUMIF($F$2:$F$9,H5,$D$2:$D$9)
```

`COUNTIF` は区分が一致する行の数を、`SUMIF` は区分が一致する行の金額の合計を返します。`J9` に `=SUM(J5:J8)` を入れて、合計が一覧の金額合計（958,000円）と一致するか確かめます。

## つまずきやすい点

- **経過日数が日付で表示される**: `E` 列の表示形式が日付になっています。「標準」に直してください。
- **区分がすべて「90日超」になる**: 請求日が文字列になっている可能性があります。セルが左寄せで「2026/9/30」と出ているときは、入力し直すか、`=DATEVALUE(C2)` で日付に直してください。
- **集計の件数が合わない**: 区分名の文字が `F` 列の数式の文字と1文字でも違うと数えられません。集計側の区分名は、数式の文字列をコピーして貼ります。
- **行を足したのに集計に入らない**: 範囲 `$F$2:$F$9` が固定されています。表の途中に行を挿入すれば範囲は広がりますが、末尾に足したときは範囲を直してください。

## 応用

### 区分の日数を変える

「30・60・90日」を「45・90・120日」などに変えたいときは、`IF` の中の数字を置き換えます。区分名も合わせて直してください。

### 入金済みの行を除く

入金済みの請求は、表から削除するか別シートへ移します。表に残したまま集計から外す方法もありますが、数式が複雑になるため、この見本は未入金の請求だけを載せる前提にしています。

### 請求日ではなく支払期日から数える

「支払期日を過ぎて何日か」で見たいときは、`C` 列を支払期日にして `=$I$1-C2` を使います。期日前のものはマイナスになるので、区分の先頭に「期日前」を足す方法もあります。どちらの数え方にするかは、社内の決まりに合わせてください。

## よくある質問

### 売掛金の年齢調べは、Excelのどの関数で作れますか？

経過日数は日付の引き算、区分分けは `IF`、区分ごとの合計は `SUMIF` で作れます。ピボットテーブルを使う方法もありますが、数式なら基準日を変えるだけで更新されます。

### 経過日数は請求日から数えますか、支払期日から数えますか？

どちらも使われます。この記事の見本は請求日からの日数です。支払期日からの日数で見たいときは、`C` 列を支払期日にすれば同じ数式で使えます。

### 基準日を今日の日付にしたいときは？

`I1` に `=TODAY()` と入力します。ファイルを開くたびに今日の日付になるので、過去の月末時点の表を保存したいときは、日付を直接入力してください。
