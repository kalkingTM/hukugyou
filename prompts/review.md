# AIレビューの採点表

記事ファイルと見本xlsxだけを読み、以下を採点する。執筆したときの意図は考慮しない。

## 一発で不合格（1つでも当てはまれば不合格）
- [ ] `verify_xlsx.py` が PASS していない
- [ ] 記事中の計算結果の例が、見本ファイルの値と食い違っている
- [ ] 税務・法律・労務について、個別の判断を断定している
- [ ] アフィリエイトリンクがあるのに `hasAffiliate: true` になっていない、または `affiliates.json` にないリンクがある
- [ ] 誇大表現・効果の約束がある（「絶対」「誰でも」「必ず」等）
- [ ] Excelのバージョン差がある機能や、祝日・税・社会保険などの制度に触れているのに、`sources` に一次情報がない（一般的なテクニックの記事に `sources` がないのは問題ない。逆に、不要な出典を水増しで付けていたら減点）
- [ ] 既存記事と同じ困りごとを扱っている

## 検索・AI引用のしやすさ（点数ではなく、直すべき点として指摘する）
- [ ] 冒頭の「結論」だけで答えが分かるか（前置きや「解説します」で始まっていないか）
- [ ] 題名の先頭に検索語の言い回しがあるか。説明は80〜120字か
- [ ] 見出しが読者の疑問・やりたいことの言葉か（「まとめ」「はじめに」がないか）
- [ ] 「よくある質問」が2〜3個あり、答えが1〜3文で直接的か（水増しの質問がないか）
- [ ] 関連する既存記事があるのに内部リンクがない、または存在しない slug へのリンクがある
- 当てはまらないものは1回だけ直してから採点する。直しても足りなければ「分かりやすさ」を減点する。

## 採点（各0〜10点、合計50点満点）
| 項目 | 見るところ |
|---|---|
| 解決力 | この記事だけで、読者の困りごとが最後まで解決するか |
| 正確さ | 数式・手順・バージョン情報が正しいか。曖昧な記述がないか |
| 独自性 | 見本ファイル・つまずき例・応用例など、AIの1回の回答では得にくい価値があるか |
| 分かりやすさ | Excel初中級者が迷わず手を動かせるか。専門用語に説明があるか |
| 薄さ・水増しのなさ | 前置きや同じ内容の繰り返しで字数を稼いでいないか |

## 合格基準
- 一発不合格の項目がない、かつ **合計35点以上**、かつ **どの項目も6点以上**。

## 出力
- 点数（合計と内訳）、合否、不合格なら理由（短く、ダッシュボードの「メモ」に載る）。
